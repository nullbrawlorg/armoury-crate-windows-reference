# Armoury Crate Windows Reference

This repository contains practical notes for setting up and maintaining ASUS Armoury Crate on Windows systems.

## Recommended Setup Order

1. Confirm Windows detects the ASUS hardware.
2. Check the Armoury Crate Devices section.
3. Complete important updates.
4. Configure Aura Sync if required.
5. Select an appropriate performance profile.
6. Add Scenario Profiles only after the basic setup is stable.

## Troubleshooting Principle

When something stops working, identify the exact symptom before reinstalling the whole application.

A missing device, failed update, RGB problem, and performance-profile issue may each have different causes.

## Keep the Configuration Simple

Use only the Armoury Crate features you actually need.

Running several RGB, fan-control, or motherboard utilities simultaneously can sometimes make troubleshooting more difficult.

For organized setup, performance, installation, Aura Sync, and troubleshooting references, see the **[Armoury Crate reference hub](https://armoury-crate.net/)**.

The best troubleshooting method is usually to change one thing at a time and test the result.
